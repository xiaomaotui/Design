## 目录用途

- `00_项目管理`：工作计划、资料台账、目录说明和版本风险记录。
- `01_原始资料/01_学校模板与要求`：学校模板、审核标准、过程材料和教师指南，不直接改写。
- `01_原始资料/02_学生当前稿件`：开题报告、学校计划表等当前工作稿快照。
- `02_参考文献原件/00_压缩包原件`：用户原有压缩包，保留不改。
- `02_参考文献原件/01_国家与行业标准`：标准 PDF 原件和压缩包解出的规范。
- `02_参考文献原件/02_现有教材与手册`：教材、图表手册和毕业设计指导书。
- `03_过程文件/01_开题阶段`：开题报告草稿、文献综述、提纲和阅读笔记。
- `03_过程文件/02_设计计算`：库容、水力、泵选型、防火堤、消防和油气回收计算。
- `03_过程文件/03_图纸`：工艺流程图、总平面图及图纸校核记录。
- `03_过程文件/04_指导与修改记录`：不少于 12 次指导记录、修改说明和中期材料。
- `04_最终成品`：说明书、图纸、答辩材料和归档材料的最终版本；过程稿不得放入。
- `90_待确认`：被 WPS 占用、参数缺失或版本存疑的项目。

- 被 WPS 占用的文件不强行移动或删除；关闭 WPS 后再处理。
