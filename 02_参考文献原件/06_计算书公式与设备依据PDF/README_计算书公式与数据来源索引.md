## 计算书公式—来源对应表（开算前使用）

| 计算项目 | 拟采用公式/方法 | 首选本地 PDF 依据 | 当前状态 |
|---|---|---|---|
| 油库设计库容 | `V_i = G_i / (K_i * rho_i * eta_i)`，并结合周转/储存天数复核 | 《油库毕业设计-指导书》PDF 15–16；设计输入冻结表给出 `G_i、K_i、rho_i、eta_i` | 可计算 |
| 装卸流量 | `Q = V / t`，质量流量与体积流量按冻结密度换算 | 《油库毕业设计-指导书》相关工艺计算页；任务书/冻结表给出的作业量和时间 | 可计算，但每条作业线需明确同时作业假设 |
| 管径初选 | `d = sqrt(4Q/(pi*v))` | 《油库毕业设计-指导书》PDF 17–19 | 可计算；流速选值须说明工况及来源 |
| 流态与沿程阻力 | `Re = vd/nu`；Darcy-Weisbach `h_f = lambda(L/d)v^2/(2g)` | 《油库毕业设计-指导书》PDF 19–22 | 可计算；摩阻系数及粗糙度必须注明取值来源 |
